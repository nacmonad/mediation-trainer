## Question

Which mode is the MVP: war-gaming (lawyer rehearses as advocate) or mediator training (human plays the neutral)?

## Answer

**Mediator training.** Resolved during charting (2026-08-27) after an initial miscommunication: the human user plays the Mediator (Z); seats A and B are LLM agents. Each seat's `human | agent` kind stays configurable so war-gaming (human as counsel) becomes a later configuration of the same engine. The app's purpose is to train mediators; the lawyer friend uses it to practice and review. Evaluation standards source material: ABA Formal Opinion 518 (2025), ABA/AAA/ACR Model Standards of Conduct for Mediators.
