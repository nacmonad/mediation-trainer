Mediator training

Practice before it matters.

Rehearse difficult mediations with independent AI Parties, private context, and an auditable Event log.

Run locally

Two independently configured Parties

Exact-audience Caucus boundaries

Local Session recovery and export

OpenAI-compatible provider choice

A mediation room, not a chatbot.

Each Party has its own model, private facts, negotiation state, and authorized view of the Session.

  1. 01

    Choose a Scenario

    Start from synthetic facts, private interests, Case resources, authority limits, and deterministic rules.

  2. 02

    Configure each Party

    Use different providers and models to compare how distinct agents negotiate the same dispute.

  3. 03

    Mediate and review

    Move between joint Session and Caucus, reach an outcome, then inspect or export the Event log.

Private by structure.

Every Event declares its audience. Each provider call is rebuilt from that Party's authorized Projection.

Domain first

Plain TypeScript owns Offers, Reaction reduction, Scenario rules, and the append-only Event log.

Provider independent

OpenAI, Venice AI, Ollama, and compatible endpoints can occupy either Party seat.

Credentials stay ephemeral

Keys live in short-lived server memory and never enter Session storage, diagnostics, or exports.

Debugging stays visible

Opt-in diagnostics expose retries, latency, token usage, sanitized payloads, and state transitions.

Scenarios should travel.

The versioned Scenario format is built for community-authored exercises, portable provider choices, and future visual tooling.
